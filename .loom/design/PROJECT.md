# Nanjing Travel Companion — Project Overview

## 产品定位

**南京旅游搭子** — 一个基于小红书攻略知识库的对话式旅游伴侣 Agent。

- **Agent 人设**：看过攻略，但和用户一样**没去过南京**的搭子。有热情、会种草、但也会说「这个我也没试过，看着不错」。
- **知识注入时机**：用户提到具体地点/场景时，检索相关攻略片段注入上下文。
- **输出形式**：对话式，短句、口语化、带个人感受。

## 数据源

**小红书** 南京旅游攻略（主要为手帐风图文笔记）：
- 图文混合：封面图 + 手帐排版 + 少量文字
- 需要 OCR 提取文字 + 图片理解提取结构化信息
- 反爬策略：限速、随机 UA、可能需要 cookies

## 技术架构

```
小红书 scraper → OCR/图片理解 → 结构化攻略 → 向量索引
                                                    ↓
用户输入（语音/文字） → 场景检索 → 注入 Agent 上下文 → 对话输出
```

### 模块划分

| 模块 | 职责 |
|------|------|
| `scraper/` | 小红书笔记抓取（图文） |
| `ocr/` | 图片文字提取（OCR）+ 图片内容理解 |
| `knowledge/` | 攻略结构化、向量索引、场景检索 |
| `agent/` | 对话 Agent（基于 Paimon 经验改造） |

## 数据格式

### 攻略片段（Chunk）
```json
{
  "id": "chunk_001",
  "source_note_id": "note_abc123",
  "location": "明孝陵",
  "type": "POI",
  "content": "明孝陵石象路秋天超美，10月中下旬最佳，建议早上8点前到避开人流",
  "media_refs": ["image_001.jpg"],
  "tags": ["秋天", "拍照", "石象路", "清晨"],
  "confidence": 0.9,
  "created_at": "2026-09-22"
}
```

### 场景索引
- POI 级别：明孝陵 / 夫子庙 / 老门东 / ...
- 场景类型：拍照 / 美食 / 住宿 / 交通 / 避坑
- 时间维度：季节 / 时段 / 人流

## MVP 范围

1. 抓取 50–100 篇南京攻略笔记
2. OCR 提取 + 结构化
3. 建立本地向量索引
4. 简单对话界面：用户问「明孝陵怎么玩」→ 检索相关攻略 → 生成回答

## 技术选型

| 组件 | 选型 | 理由 |
|------|------|------|
| Scraper | xiaohongshu-mcp / playwright | 图文混排，需要浏览器渲染 |
| OCR | 百炼通义千问 VL / PaddleOCR | 手帐风图片，需要视觉理解 |
| Embedding | 百炼 qwen3.7-text-embedding-flash | 与 Paimon 同一供应商，0.000125元/百万 token |
| 向量库 | 本地 JSON + 余弦 top-k | Demo 阶段，数百条暴力检索足够 |
| Agent | 基于 Paimon 人设改造 | 毒舌可爱 + 旅游搭子语气 |

## 与 Paimon 的关系

- **独立项目**，不混入 Paimon 代码库
- **复用 Paimon 经验**：
  - PRISMIX prompt 分层
  - 流式输出 + 边收边播
  - 记忆系统设计
- **差异化**：
  - 知识库驱动（Paimon 无外部知识库）
  - 场景化检索（不是自由对话）
  - 图文混合输入（OCR 是关键）
